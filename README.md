# 计算机视觉实验三：图像拼接

## 内容

| 文件 | 说明 |
| --- | --- |
| 实验三_图像拼接.ipynb | Jupyter版，按2.1~2.7逐节运行，图片直接显示在单元格下方 |
| 实验三_图像拼接_实验报告.docx | 实验报告，含5张结果图 |
| a.jpg | 原始图像A |
| b.jpg | 原始图像B |
| output_images/ | 输入图像对比、SIFT关键点、匹配结果 |
| result/ | 拼接结果、重叠区差异图 |

## 实验步骤

2.1 导入依赖
2.2 读取图像并转灰度
2.3 SIFT特征检测
2.4 FLANN匹配与Lowe比率检验
2.5 RANSAC估计单应矩阵
2.6 透视变换与画布拼接
2.7 拼接质量检查

## 运行

需要numpy、opencv-python、matplotlib。

Jupyter版：把a.jpg、b.jpg和notebook放同一目录，Kernel → Restart & Run All。

## 结果

a图为1280×1068，b图为1280×1161，检出关键点3192和4411个。比率检验后保留1112对匹配，RANSAC内点1101个，内点率99%。估计的单应矩阵为x方向平移-638.761、y方向0.325，近似纯平移。内点平均重投影误差0.29像素。拼接画布1707×1280，重叠区平均灰度差2.01，黑边占比0.05%。
